# VirtualMarketInsight

**See what is possible. Understand what it requires. Put the resources behind it. Make it happen.**

VirtualMarketInsight (VMI) is the market, capital, opportunity and execution front door for the Highest Degree Priorities ecosystem.

## vNext public surfaces

1. **Explore Markets** — companies, sectors, commodities and economic relationships.
2. **Talk to an Analyst** — evidence-grounded company, industry, portfolio and capital intelligence.
3. **Explore Opportunities** — operating opportunities beyond financial assets.
4. **Deploy Operational Capital** — map requirements, capabilities, resources, capital and next actions.
5. **Agent Marketplace** — specialized research, screening, portfolio, commodity, risk, signal and operating agents.

## Shared execution graph

`Opportunity → Requirements → Capabilities → Capital → Project → Execution`

Supporting objects include Resource, Organization, Capital Mandate, Evidence, System and Transaction.

## Deployment shape

- `virtualmarketinsight.com` / `www.virtualmarketinsight.com`: static GitHub Pages front end.
- `api.virtualmarketinsight.com`: controlled VPS gateway (not directly exposed internal orchestration).
- `C:\HDP\VMI`: VPS working/deployment directory.
- Internal systems remain private and are integrated through bounded, allowlisted interfaces.

See `docs/ARCHITECTURE.md` for the operating boundary.
